Step 3(`line_art_conversion`, 컬러 패턴 → 재단선만 남긴 스케치)에서 프롬프트를 여러 판본 고쳐도 결함이 자리만 옮기는 상태가 2026-08 기준으로 이어지고 있음.

**Why:** `config/gemini_config.py`의 `temperature=0`은 텍스트 스텝만 결정적으로 만들고 이미지 생성 스텝은 그렇지 않음. 같은 입력·같은 조건으로 돌린 `images/output-1` ~ `output-4`를 재보면 잉크 면적(adidas 6.7% / 12.4% / 6.9% / 11.9%)과 흐린 획 비율(adidas 0.02% / 21.6% / 0.00% / 0.01%)이 판본 간 차이만큼 크게 흔들림. 즉 판본당 1장씩 뽑아 비교한 지금까지의 실험은 프롬프트 효과와 표본 잡음을 구분할 수 없었음. Step 2 쪽 함정은 [[step2-symmetry-defect]] 참고 — 그쪽은 반대로 Step 1이 결정적이라는 점이 함정이었음.

**How to apply:**
- Step 3 프롬프트 변경 효과를 판단할 때는 조건당 최소 5회, 신발 3종을 돌리고 중앙값으로 비교할 것. 1장 대 1장 비교로 "회귀했다/좋아졌다"고 결론 내지 말 것.
- 판정은 눈이 아니라 픽셀 지표로: 입력 대비 실루엣 IoU, 화면비 편차, 유채색 픽셀 비율, 25×25 침식 후 남는 검정 면적(면 채움), 21px 국소최소값이 90을 넘는 잉크 비율(흐린 획). 정상 실행과 붕괴 실행이 이 지표들에서 자릿수 단위로 갈림.
- 폐기된 보조 이미지(Lab-L, sigma≈56 블러 + 국소 정규화) 재도입 제안은 반려 대상. `images/output-3/*_aid.png`를 직접 보면 흰 배경이 검게 뒤집히고 펀칭 구멍·앞코 디테일이 통째로 뭉개진 것이 확인됨. 보조 이미지가 있었던 실행과 없었던 실행의 품질 차이도 측정되지 않음.
- 외곽 실루엣은 모델이 거의 항상 잘 맞추는 부분(IoU 0.85~0.99로 실행 간 안정)이라 '증거'로 넣을 값어치가 없음. 대신 붕괴 실행을 걸러내는 '검증 게이트'로 쓰는 것이 맞음.
